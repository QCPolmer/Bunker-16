I vibe coded this with gemini
(mostly, the save-page functionality was homebrew)

The idea here is it makes it easy to 
create a 'gui' ish thing for linux/configs/code,
purely on the web page. 

It also has file encryption tools,
a WASM/data to js converter, 
(to allow use of WASM's with no backend)
and can be modified and saved 
(using the on-page save feature)
to give a full-copy of the page.
